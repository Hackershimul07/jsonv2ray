VLESS লিংক → JSON কনফিগ

সংস্করণ ৫

যেকোনো vless:// লিংক পেস্ট করুন। একসাথে অনেকগুলোও দেওয়া যায়, এমনকি সাবস্ক্রিপশন (base64) টেক্সটও। টুল অ্যাপের নিয়ম অনুযায়ী নিজে ঠিক করে নেয়, আর শেষে যাচাই করে জানায় JSON চলবে কি না।

ডোমেইনের IP Cloudflare DNS বা Google DNS থেকে আনা হয়। না পেলে নিজের IP লিখে দিতে পারবেন।

TLS ছাড়া VLESS ট্রাফিক এনক্রিপ্ট করে না। ফোন থেকে সার্ভার পর্যন্ত পথে অন্য কেউ ট্রাফিক দেখতে পারে।
